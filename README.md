## 진행 방법

1. 매일 아침 새로운 "오늘의 경험 {날짜}" 이슈가 생성됩니다.
2. 이미 해본 항목은 **완료** 체크박스를, 해보고 싶은 항목은 **⭐ 해보고 싶어요** 체크박스를 눌러주세요.
3. 다음날 체크 상태가 completed_log.json / wishlist_log.json 에 자동 반영되고, 이 README도 갱신됩니다.
